## 🧠 Overview

**Enscape** is a real-time visualization application designed to work directly alongside architectural and BIM modeling software, enabling users to generate interactive renderings, animations, walkthroughs, and virtual reality presentations while continuing to edit the original project model.

The platform focuses on seamless integration with professional design workflows, allowing every model modification to appear instantly inside the rendered environment. This live connection helps architects and designers evaluate materials, lighting, spatial composition, and presentation quality without interrupting the modeling process.

Created for architects, BIM managers, interior designers, landscape designers, visualization professionals, and Windows users.

---

## 🚀 Key Features

| Feature | Description |
|----------|-------------|
| 🔄 **Instant Model Synchronization** | View design changes immediately inside the rendered scene as the source project is updated. |
| 🏛️ **Native BIM & CAD Integration** | Render directly from supported architectural and modeling applications without complex export procedures. |
| 🌤️ **Interactive Environmental Controls** | Adjust daylight, artificial lighting, weather, atmosphere, fog, shadows, and sky conditions in real time. |
| 🪟 **Advanced Material Rendering** | Apply realistic glass, concrete, wood, metal, stone, water, and custom surface properties with physically based shading. |
| 🎥 **Presentation & Animation Tools** | Create walkthroughs, flyovers, panoramas, cinematic sequences, and client-ready architectural presentations. |
| 🥽 **Immersive VR Experiences** | Explore projects at full scale using virtual reality for design validation and stakeholder reviews. |
| 🌳 **Integrated Asset Collection** | Populate scenes with vegetation, furniture, people, vehicles, lighting fixtures, and decorative objects. |
| 📤 **Multiple Output Formats** | Export high-resolution images, videos, panoramas, executable presentations, and shareable project media. |
